FROM SKETCHBOOK TO PANEL

Deploy over USB.

The board needs the Widget Studio scene-player firmware once. After that, layouts upload as data and survive a restart.

One-time firmware setup

With the board connected and its serial monitor closed, run these commands from DeskDisplay. This installs the scene player and keeps the Clock and Island modes available.

.\scripts\idf.ps1 build
.\scripts\idf.ps1 -p COM4 flash

Uploads use the local preview server. Or send a downloaded package with:

.\.tools\host-python\Scripts\python.exe scripts/device.py --port COM4 deploy face.fls
